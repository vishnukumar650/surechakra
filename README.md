SureChakra is a Chakra meditation web app built with React, Tailwind CSS, and Workbox. It presents the chakra system with simple visuals, chakra detail pages, chants, and a mobile-friendly experience that behaves like a lightweight PWA.

## Features

- Chakra overview page with guided entry points
- Individual chakra detail pages with chants and supporting information
- Responsive layout for desktop and mobile
- Dark and light theme support
- PWA-ready build with offline-friendly assets

## Tech Stack

- React 18
- React Router
- Tailwind CSS
- Workbox
- gh-pages for deployment

## Getting Started

### Prerequisites

- Node.js 16 or newer
- npm

### Install

```bash
npm install
```

### Run locally

```bash
npm start
```

The app runs at `http://localhost:3000/surechakra/`.

### Build for production

```bash
npm run build
```

## Available Scripts

- `npm start` - start the development server
- `npm run build` - create a production build
- `npm test` - run the test runner
- `npm run deploy` - publish the build to GitHub Pages

## Deployment

The project is configured for GitHub Pages with the homepage set to:

```json
"homepage": "https://surechakra.vercel.app/surechakra"
```
